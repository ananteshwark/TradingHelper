# Calling the bottom

`PROTOCOL.md` (fingerprinted and committed before any result), `bottoms.py` (the six rules,
the trades and the timing measures). Outputs: `dev.txt` (2013-2020), `CHOICE.md`,
`confirm.txt` (the one confirmation run, 2021 to 8 October 2026). Write-up:
`docs/BOTTOMS.md`.

The script ran on the price panel of `research/promoter/build_all.py` and NSE's delivery
files (`uv run python -I bottoms.py SCRATCH dev`); the downloaded data is not kept in the
repository.
